# 🌐 Portfolio Website - Mihir Patil

A modern, responsive portfolio website built with **React.js** and **Tailwind CSS**, showcasing **skills**, **projects**, and **professional experience**.

---

## 🚀 Features

- **Responsive Design** – Fully optimized for all devices  
- **Modern UI/UX** – Clean and professional interface  
- **Smooth Navigation** – Active section highlighting  
- **Skills Showcase** – Organized skill display with icons  
- **Portfolio Section** – Dynamic project showcase  
- **Contact Integration** – Social links and contact options  

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS  
- **Icons:** React Icons  
- **Build Tool:** Vite  
- **Styling:** Custom CSS with Tailwind utilities

## 🎨 Customization Guide

### 🧍 Personal Information
Update personal details in:
- \`src/components/Hero.jsx\` → Name, description, roles  
- \`src/data/data.jsx\` → Skills, experiences, portfolio items  

### 🎨 Styling
- Modify colors using Tailwind utility classes  
- Update fonts in \`src/index.css\`  
- Replace background image in \`src/assets/\`  

### 🧩 Content
- Add/remove skills in \`skillsData\`  
- Update projects in \`portfolioItems\`  
- Edit work experience in \`experiences\`
